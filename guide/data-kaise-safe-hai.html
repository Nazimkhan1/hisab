Hisab Kitab mein aapka data kaise safe hai

Hisab Kitab Guide · NextGrade

Paise ka hisab niji cheez hai. Isliye Hisab Kitab is tarah bana hai ki aapka data sirf aapke paas rahe.

Data kahan rehta hai

  • Bina login: sirf aapke phone ke browser mein.
  • Google login ke saath: aapke apne Google Drive mein “Hisab Kitab” folder mein. Har tareekh ki alag file hoti hai jo aap khud khol sakte hain, aur sync ke liye ek _sync-data.json file.

App banane wala kya nahi dekh sakta

Hisab Kitab ka koi apna server ya database nahi hai. Koi admin panel ya user list nahi hai. Isliye app banane wala na aapka hisab dekh sakta hai, na badal sakta hai, na mita sakta hai.

Drive ki permission kitni hai

App sirf ek Drive permission maangta hai (drive.file), jisse wo sirf apni banayi files aur folder use kar sakta hai. Aapki photos, documents ya baaki Drive files app nahi dekh sakta.

Login kaise hota hai

Login Google ki apni screen par hota hai; app ko aapka password kabhi nahi milta. Google se mili access ek ghante mein khatam ho jaati hai aur sirf memory mein rehti hai.

Aapke haath mein kya hai

  • Koi bhi entry kabhi bhi hatayein.
  • Drive mein “Hisab Kitab” folder delete karke saara data mita dein.
  • myaccount.google.com/permissions se app ki access hata dein.
